# Example: a multilingual app page

This is a hypothetical brief for demonstrating the workflow. It is not a completed client project or a claim about an existing application.

## Request

Improve a product page in Russian, English, and Kazakh. Keep its established colors, logo, routes, and install destination. The supplied mascot can react to a tap. The page should remain comfortable to scroll on a phone.

## Product material

- Verified name, description, install URL, and screenshots come from the product owner's project files.
- No usage counts, awards, customer quotations, or performance improvements have been supplied.
- The mascot is a decorative illustration, not a product screenshot.

## Direction

Use one dominant product image with a short promise and one install action. Let the mascot mark the transition from the introduction to the product walkthrough. Use the existing brand colors as roles for surface, text, and action.

## Language cases

| Element | RU | EN | KK |
| --- | --- | --- | --- |
| Main action | Посмотреть приложение | View the app | Қолданбаны көру |
| Locale control | Язык | Language | Тіл |
| Interaction action | Поздороваться | Say hello | Сәлемдесу |

These example translations are drafts for layout work. Product copy still needs review in the project's language process.

## Interaction cases

- Tap or keyboard activation of the visible greeting button triggers the same response.
- A swipe outside the mascot interaction region scrolls the page normally.
- Cancelling a gesture returns the illustration to a stable state.
- With reduced motion, the greeting uses a still state or brief non-spatial feedback.
- Device tilt is optional and does not unlock essential content.

## Evidence to gather

Check the first screen and menu in all three locales, then perform greeting and scroll actions on the target phone or an explicitly named emulation. Record the viewport, the actual action, and the result. Leave the report marked unverified until those checks have happened.
